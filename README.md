# Welflow — 영문 복지행정 스타트업 홈페이지

## 결과물

대한민국 복지서비스 이용을 돕는 가상 스타트업 **Welflow**의 영문 반응형 홈페이지입니다.

- 메인 문구: **Less searching. More support.**
- 방향: 주민이 복잡한 제도명 대신 생활 속 필요를 출발점으로 삼도록 설계
- 디자인: 크림색 바탕, 딥그린 타이포그래피, 코럴색 주요 버튼, 연두색 보조 요소
- 구성: 첫 화면 → 복지 분야 탐색 → 이용 과정 → 담당자 도구 → 자주 묻는 질문 → 시작하기 → 하단 안내

## 실행

`index.html`을 Chrome 또는 Edge 등 브라우저로 여십시오. 별도 패키지 설치나 빌드가 필요하지 않습니다. HTML, CSS, JavaScript와 SVG 아이콘이 하나의 파일에 포함되어 있습니다.

일반적인 정적 웹 호스팅에 게시할 때도 이 파일을 첫 페이지로 사용할 수 있습니다. 실제 인터넷 사이트로 배포하는 작업은 수행하지 않았습니다.

## 구현 기능

| 기능 | 구현 내용 |
|---|---|
| 분야 탐색 | 가족·보육, 주거·생활, 일자리·소득, 건강·돌봄, 장애·접근성, 노년기 분야 |
| 검색·필터 | 영문 키워드 검색, 분야 그룹 필터, 검색 결과 없음 안내 및 초기화 |
| 시작 안내 | 이용 대상 선택 → 관심 분야 선택 → 상담 준비 안내 |
| 파일 저장 | 분야별 상담 준비 질문 및 담당자 체크리스트를 TXT로 저장 |
| 담당자 도구 | 상담 준비 항목 체크, 출력, TXT 저장 |
| 외부 이동 | 복지로, 정부24 링크 |
| 부가 요소 | 모바일 메뉴, 질문 펼치기, 개인정보·시연 범위 안내 |
| 접근성 고려 | 키보드 조작, 초점 표시, 본문 바로가기, 기본 모달 동작, 동작 감소 설정 대응 |

## 시연 범위

Welflow는 실제 운영 기업 또는 정부기관을 나타내지 않는 **가상 브랜드**입니다. 정부의 공식 서비스 또는 제휴 서비스로 표시하지 않았습니다.

실제 자격 판정, 급여액 산정, 신청 접수, 행정정보 조회, 사용자 인증, 사례관리 기록 저장, 실시간 복지사업 데이터베이스는 연결하지 않았습니다. 분야별 문구와 체크리스트는 설명용 구성입니다. 현행 제도의 지원 대상, 금액, 제출 서류, 신청 기한을 대신하지 않습니다.

실제 서비스 운영을 검토할 때는 다음 사항을 확인해야 합니다.

- 복지사업별 공식 데이터·갱신 체계: **[확인 필요]**
- 개인정보 처리 및 기관 보안 기준: **[확인 필요]**
- 행정정보·신청 시스템 연계 권한 및 API: **[확인 필요]**
- 기관 업무절차에 맞춘 상담 양식: **[확인 필요]**
- 브랜드명·상표 사용 가능 여부: **[확인 필요]**
- 정식 웹 접근성 점검 및 운영 환경별 품질 검증: **[확인 필요]**

## 데이터 처리

페이지는 계정, 주민등록번호, 연락처, 소득 등 개인정보를 요청하지 않습니다. 선택과 검색은 현재 페이지의 메모리에서만 처리되며 서버로 전송하지 않습니다. 쿠키, 분석 도구, 외부 폰트, 추적 스크립트, 제3자 스크립트는 포함하지 않았습니다.

직접 저장한 TXT 파일은 이용자 기기에 남습니다. 홈페이지를 별도 서버에 게시하면 호스팅 사업자의 접속 로그가 발생할 수 있으므로 운영 단계에서 별도 확인이 필요합니다. 외부 사이트로 이동한 뒤에는 해당 사이트의 정책이 적용됩니다.

## 연결한 외부 자료

- 복지로: https://www.bokjiro.go.kr/ssis-tbu/
- 정부24: https://plus.gov.kr/

제작 과정에서 홈페이지 연결 주소를 확인했습니다. 사업별 정책 데이터는 수집하거나 전재하지 않았습니다.

## 검수

Chromium 브라우저에서 HTML을 렌더링하여 화면과 기능을 점검했습니다. 320, 375, 390, 560, 768, 850, 1024, 1280, 1440, 1920픽셀 화면 폭에서 가로 넘침이 없는지 확인했습니다. 검색, 필터, 안내 단계 이동, 분야별 팝업, TXT 저장, 담당자 도구, 개인정보 안내, 질문 펼치기, 모바일 메뉴를 시험했습니다.

상세 결과는 `qa-results.json`에 있습니다. 이 검수는 정식 접근성 인증이나 모든 브라우저·기기에 대한 검증을 의미하지 않습니다.

## 파일 구성

- `index.html`: 홈페이지 전체 소스 및 실행 파일
- `README.md`: 실행·편집·시연 범위 안내
- `qa-results.json`: 자동 점검 결과
- `previews/`: PC·모바일 화면 이미지

## 편집 위치

- 브랜드 및 주요 영문 문구: `index.html`의 본문 영역
- 색상: `<style>`의 `:root` 변수
- 지원 분야 및 질문: `<script>`의 `SUPPORT_AREAS`
- 담당자 체크리스트: `PROFESSIONAL_ITEMS`
- 화면 폭별 배치: `<style>`의 `@media` 영역

별도 폰트 파일은 포함하지 않았습니다.
